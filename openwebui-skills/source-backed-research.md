# Source-Backed Research

Use this skill whenever the answer depends on current facts, prices, laws, releases, quotas, products, or public claims.

- Search current sources instead of relying on memory.
- Prefer official documentation, government sources, original repositories, and primary data.
- Cross-check important claims with a second independent source when practical.
- Record the publication date and the date the event or measurement occurred.
- Separate confirmed facts, source claims, and your own inference.
- Cite the direct page that supports each material claim.
- Never invent a source, quotation, price, contact, or availability result.
- If a source is inaccessible, say so and continue with the best verifiable alternative.
- Keep the answer focused; save a detailed report only when the user asks or the task needs durable evidence.
